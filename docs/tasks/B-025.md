## 진행·인계

- 컴퓨터 문제 1은 큐브 위치·크기, 문제 2는 열쇠 조각 회전. 정답에서만 E로 방출. 해결 후에는 1/2로 물체를 선택해 자유 조작·반납 가능
- 장롱은 잠금 해제 후 E로 열고 열린 상태 유지. 정렬에 쓴 큐브를 회수해 다시 크게 만들어 선반 문짝 발판으로 사용
- Home 모형은 장롱 우상단으로 이동하고 Y축 90도 회전. 책장·벽·빗장과 착탄의 좌표 변환을 함께 반영
- 학교·회사 모형은 대표 형태로 먼저 전시, 새누의 원본 모형 연결은 후속. 군대는 기존 Blender 생활관 자산 재사용. 새누 담당 학교·회사 소스와 공용 Player는 수정 대상 아님
- 시점 판정은 내 방에서 별도 구현. 새누의 소스 코드를 실제로 재사용했다고 표현하지 않음
- 공유 기준: `origin/main` `4e55819`, `origin/saenu` `cf997cb`; 추가 공유 변경 없음
- 컴퓨터 전용 숨김 OpenGL 검사 10개 통과. 오답 보존, 순서 잠금, 두 문제 정답·방출, 중복 방지, 반납한 큐브의 발판 크기 확대와 GL 오류 없음 확인
- 첫 전체 빌드에서 MSVC `C1128`(개체 파일 섹션 한도) 발생. 확장한 게임 메시를 컴파일하도록 HomeRoom.cpp에만 `/bigobj` 적용, 학교·회사 컴파일 설정 유지
