## 진행과 인계

- [main.cpp](../../project_code/Out_of_Scale/main.cpp)에 격자 평면, 시선 기준 WASD 이동, 마우스 회전과 중앙 조준점을 추가했다. 실행 창이 포커스를 얻으면 커서를 캡처하고 포커스 전환 시 마우스 위치의 기준을 새로 잡는다. Esc는 창을 종료한다.
- [솔루션](../../project_code/Out_of_Scale/Out_of_Scale.slnx)은 실습용 OpenGL 라이브러리가 설치된 x64에 맞췄다. `Out_of_Scale.vcxproj`는 Windows SDK 10.0.26100.0에 설치된 GLFW·GLEW·GLM을 사용한다. 중첩 빌드 캐시는 Git에서 제외한다.
- Debug·Release x64 솔루션 빌드가 통과했다. GLEW 디버그 심볼 파일 관련 LNK4099 경고가 있었다.
- Debug 실행 창에서 격자 평면을 확인했다. UI 자동화로 마우스를 움직여 시점이 바뀌고 조준점이 중앙에 유지되는 것을 확인했다. W 전진과 Esc 종료도 확인했다. 포커스 왕복과 연속 키보드 입력은 별도 확인 항목이다.
- [개발 계획의 코드 구조](../../illusion-escape-game-plan.md#10-코드-구조와-작업-폴더)에 현재 진입점과 실행 방법을 반영했다. 로컬 변경이며 기존 군대 맵 스테이징을 유지했다.

## 2026-11-09 — 빌드 중간 파일 경로 정리

- 최윤서 요청으로 [Out_of_Scale.vcxproj](../../project_code/Out_of_Scale/Out_of_Scale.vcxproj)의 `IntDir`을 `%LOCALAPPDATA%\out-of-scale\build\<프로젝트 경로 해시>\<플랫폼>\<구성>\`으로 옮겼다. 기존 프로젝트 내부 중간 파일 폴더는 Windows 임시 폴더로 이동했다. 실행 파일 경로는 기존 `x64/<구성>/`이다.
- Debug·Release x64 솔루션 빌드 후 중간 파일과 실행 파일이 각 경로에 있고 중첩 폴더가 생기지 않는 것을 확인했다. 소스 수정 없이 Debug를 다시 빌드했을 때 기존 개체 파일을 재사용했다.
- 팀원별 빌드 중간 파일은 각 PC의 사용자 폴더에 저장된다. 사람 검토는 미확인이다.
