- [국회예산정책처 군 복무여건 개선사업 평가](https://nabo.go.kr/board/file/down.do?fid=33318059)의 국방부 생활관 사진에서 침대, 중앙 통로, 창과 커튼, TV를 참고했다. 게임에 맞게 침대 다섯 개와 관물대를 양쪽에 배치하고 두 번째 구역의 배경을 산악 훈련장으로 바꿨다.
- 통로의 군장·침구·장비 상자를 가까이에 놓아 줄이고 각 정리 칸에 넣는다. 세 물건을 모두 정리하면 TV가 켜진다. TV를 더 멀리 배치해 키운 뒤 검은 화면에 걸어 들어가면 시선이 이어진 채 훈련장에 도착한다.
- [군대 방 코드](../../rooms/military/MilitaryRoom.cpp), [입력·장면 루프](../../project_code/Out_of_Scale/main.cpp), [Blender 맵](<../../rooms/military/design/군대 방 맵.blend>), 게임 메시·내보내기·미리보기, [기획서](../../illusion-escape-game-plan.md)를 반영했다. 초소의 창, 달, 참호, 기둥, 출구 메시를 기존과 비교했고 Blender에서 재내보내기 결과가 일치했다.
- Release x64 재빌드와 자동 검증 43개 통과. 정리 칸 불일치, 세 물건 정리 전 TV 잠김, 작은 TV와 잘못된 접근의 통과 차단, 커진 TV를 통과한 뒤 달 퍼즐과 전역 출구까지 확인했다. 게임 렌더러로 시작, 정리 완료, TV 출입구와 훈련장 모습을 확인했다. 게임 창 직접 조작과 사람 검토는 미확인이다.
- 로컬 작업 상태. 커밋·푸시·통합은 미수행이다.

## 생활관 사진 배치 반영

- 첨부 사진에 맞춰 침대 발치가 통로를 향하도록 양쪽에 다섯 자리씩 배치하고, 머리맡에 관물대를 붙였다. 방 끝의 창 두 개 사이에 TV를 뒀다. 중앙 테이블을 빼고 정리 칸은 벽 쪽으로 옮겼다.
- Blender 바닥과 벽, 침대·관물대 메시를 새 배치로 바꿨다. 방 폭은 7.2m, 천장 높이는 4.6m다. 출입구·스폰·정리 대상·TV 좌표와 가구 충돌 범위를 새 배치에 맞췄다.
- Release x64 재빌드 통과. 확장된 바닥과 가구 충돌을 확인했고, 자동 검증 45개에서 정리, TV 진입, 초승달과 그림자 다리, 전역 출구까지 확인했다.

## Blender 생활관 디테일 보강

- 침구에 둥근 모서리, 주름과 박음선을 넣고 관물대에 열린 수납칸, 선반, 재킷·군장·전투화를 추가했다. 창에는 주름 커튼, 손잡이와 난방기를, 바닥에는 색이 조금씩 다른 비닐 타일을 넣었다.
- Blender에서 천과 도장면의 입자, 창빛과 형광등을 조정했다. 형상, 타일 색상, 밝은 유리와 형광등 색은 게임 메시에도 반영했다. Blender의 표면 질감과 조명은 미리보기에서 확인할 수 있다.
- 모든 가구 메시가 기존 충돌 범위 안에 있는지 확인했다. 훈련장의 구조와 초승달 내보내기는 이전과 일치했다.
- Blender Cycles 1500×950 렌더 확인, 메시 재내보내기 일치, Release x64 재빌드와 자동 검증 45개 통과. 게임 렌더로 새 생활관을 확인했고, TV 너머 초소와 달빛 다리의 비교 이미지도 일치했다.

## Blender 야간 산악 훈련장 디테일 보강

- 창밖에 겹친 산 능선, 경사면, 침엽수와 화강암을 배치했다. 초소에는 콘크리트 패널·창틀·기둥 디테일을, 참호에는 보강재와 경계등을 추가했다. 푸른 달빛과 호박색 초소등을 Blender에서 조정했다.
- [Blender 원본](<../../rooms/military/design/군대 방 맵.blend>)에 야간 초소와 참호 카메라를 추가하고 게임 메시를 내보냈다. 창의 달 조준, 참호와 다리의 범위, 생활관 구조를 비교 검증했다. 새 외곽 지형은 달 조준선 3,115개를 가리지 않았다.
- Blender Cycles 1500×950 렌더를 확인했고, 내보내기 재현, Release x64 재빌드, 자동 검증 45개가 통과했다. 게임 렌더에서 창밖 초승달과 참호 다리, 출구 조명을 확인했다.
