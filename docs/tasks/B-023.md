## 진행·인계

- 조작: E 화면 사용·큐브 꺼내기·집기·놓기·반환, 화면 안 방향키 이동·Q/R 회전·휠 크기, Tab 화면에서 나오기, Esc 공통 일시정지
- 공용 Player API는 기존 `setRoomPosition` 재사용. 학교·회사 코드와 학교 퍼즐은 수정하지 않음
- `ComputerScreen`이 화면 속 큐브의 위치·Y축 회전·한 변 길이를 관리. 640×360 FBO 결과를 벽 모니터에 표시하며, 상태가 바뀐 경우에만 화면 텍스처를 다시 그림
- 큐브 한 변은 0.40~1.00m. 화면 밖에서도 크기·회전값을 유지하고, 가구 앞의 유효한 위치에 놓으면 중력으로 바닥·가구 위에 떨어짐. 회전한 큐브 충돌과 플레이어의 착지·머리 접촉·내려오기 연결. 모형에도 같은 위치·크기의 작은 큐브 표시
- 화면을 사용하는 동안 이동·점프·RPG 입력 차단, 조작 안내 표시. Tab으로 원래 시점 복귀, 다른 맵으로 이동하면 화면 조작만 종료하고 큐브 상태 보존
- 실제 수정: `rooms/home/HomeRoom.h/.cpp`, `ComputerScreen.h/.cpp`, Blender 제작 스크립트·원본·메시·미리보기, `main.cpp`, `.vcxproj`와 `.filters`, 공식 기획서와 이 기록
