## 2026-11-19 — RPG 비행과 벽 파괴 효과

- 사용자 수정에 따라 책장 뒤 벽을 주변 벽과 같은 색·두께로 구성하고, 균열과 파괴 전 문틀 표시를 제거함
- RPG 발사체가 날아가 부딪힐 때 섬광·불꽃·먼지와 벽 파편을 생성함. 책장·책상·다른 벽에 맞으면 해당 위치에 효과를 내고 재발사 가능
- 비행 중 추가 발사는 차단하고 고정된 파티클 개수와 수명을 사용함. 벽 파괴 후 문을 장착·열고 걸어 나가는 흐름 유지
- 최종 소스 Debug·Release x64 빌드 통과. 숨김 OpenGL 퍼즐 검사 43개와 공용 게임 루프 검사 36개 통과
- 발사 직후 벽 유지, 탄 이동 후 착탄·파괴, 상단 벽과 가구에 막히는 오발, 재발사와 문 탈출 확인. 비행·효과의 Esc 정지와 다른 맵 전환 중 시간 보존 확인
- 발사 직후 꼬리가 카메라에 겹치던 문제와 파괴 전 벽의 박스 경계선을 화면 검사로 발견해 수정함. 사람의 직접 플레이는 미검증
- 커밋 직전 `origin/main` `615de34`와 `origin/saenu` `cf997cb`의 공유 상태·학교 인계 확인. 공통 API 변경 없음. 이 갱신도 구현과 함께 `origin/yoon778`에 공유하며 `main` 통합은 별도

### 불규칙한 벽 파편 보강

- 벽을 18개의 서로 다른 다각형으로 나눠 두께 있는 파편 메시 생성. 조각별 크기·윤곽·발사 방향·회전 속도가 달라지고, 착탄 위치에서 바깥으로 흩어짐
- 메시를 방 초기화 때 한 번 업로드하고, 파괴 시 각 파편의 위치·회전만 갱신. 회전된 정점으로 바닥 높이를 구해 파편 낙하·튕김 처리
- 최종 Debug·Release x64 빌드와 기존 OpenGL 퍼즐 검사 43개 통과. 충돌 직후·0.15초·0.4초 게임 화면에서 모양과 회전 차이 확인. 직접 키보드·마우스 조작은 미검증
- 파편의 면적 합이 원벽의 4.68㎡와 일치하고 두께가 0.31m임을 검사. 46,800개 평면 표본에서 조각 누락·겹침 없음
