## 검증

- Blender 5.2.2에서 원본 생성과 재내보내기 완료. 9개 메시 범위, 45,688개 삼각형. 좌표·색상·범위 검수 통과. 재내보내기 SHA256 일치
- 실물과 모형이 같은 GPU 메시를 공유하고, 재질의 음영·주변광 차폐를 내보내기 때 정점색에 반영함
- 최종 팀 솔루션 Debug·Release x64 빌드 통과. 숨김 OpenGL 퍼즐 검사 43개와 공용 게임 루프 검사 36개 통과
- 책장 연동, RPG 비행·파편, 문 확대·장착·도보 탈출, Esc 정지와 맵 복귀 상태 보존 확인. 실제 게임 캡처에서 실내와 모형의 침대·책상·서랍장·책장 배치 대응 확인
- 파괴 전 벽의 패치가 조명 차이로 보이던 문제를 단일 연속 벽으로 수정해 주변 색상과 일치 확인
- 새 모델의 사람 직접 조작은 미검증. 기존 박스 퍼즐은 사용자가 직접 확인했다고 전달받음
- 커밋 전 `origin/main` `615de34`와 `origin/saenu` `cf997cb`의 학교 인계·팀 현황 확인. 이번 변경과 기록은 `origin/yoon778`에 공유하며 `main` 통합은 별도
