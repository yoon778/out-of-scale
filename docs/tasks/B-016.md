## 진행·인계

- [공용 진입점](../../project_code/Out_of_Scale/main.cpp)이 [PauseMenu](../../project_code/Out_of_Scale/src/core/PauseMenu.h) 하나를 소유함. Esc로 상태를 전환하고, 메뉴 버튼과 Enter·Q를 처리함
- 정지 중에는 시점·이동·점프·물리와 상호작용을 멈춤. 이어갈 때 마우스 기준과 프레임 시간을 갱신함
- [학교 실행 연결부](../../rooms/school/SchoolPreview.h)의 선택 콜백으로 같은 메뉴를 연결함. 학교 퍼즐·복도·렌더러·에셋은 머지본을 그대로 사용함
- 팀 실행의 F1~F4와 일시정지 중 학교 R 초기화는 개발용으로 유지함. 학교 단독 미리보기는 기존 일시정지 메뉴를 사용함
- Debug·Release x64 빌드 통과. Release 검증에서는 전체 프로그램 최적화 해제 옵션을 사용함
- OpenGL 통합 검사 20개와 기존 학교 퍼즐 검사 184개 통과. 정지 중 이동·시점 차단, 양쪽 Esc 재개, 메뉴 클릭과 단축키, F2 이동을 확인함
- 실제 Debug 창에서 학교 Esc·이어하기 클릭, 군대 Esc·종료 클릭을 확인함. 학교 연결부 두 파일 외의 학교 소스와 에셋은 머지본과 일치함

## 새누 AI 인계

- 팀 게임의 Esc와 메뉴 상태는 `main.cpp`와 `src/core/PauseMenu`가 관리함. `school::PreviewNavigation::pause`가 팀 메뉴를 학교 반복 루프에 연결함
- 학교나 회사의 퍼즐을 붙일 때 공용 정지 상태를 따라 업데이트를 멈추고, 재개 시 입력 기준을 갱신함. 학교 단독 실행에서는 이 콜백 없이 기존 조작을 사용할 수 있음
