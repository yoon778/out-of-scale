# DOC-20261110-01 — 큐브 집기·놓기와 원근 크기 변경

- 2026-11-10 최윤서 작업을 지원한 Codex. `yoon778`의 `2acefa8`에서 시작했다. 개발 계획의 규칙 B와 `origin/main`·`origin/saenu`의 관련 작업 기록을 확인했다.
- [TestRoom](../../rooms/test/TestRoom.cpp)에 주황색 큐브 하나를 놓았다. 조준 광선이 큐브의 현재 크기로 계산한 상자 범위와 교차할 때 E로 집는다. 다시 E를 누르면 미리 보인 위치와 크기로 바닥에 놓인다. 시선이 하늘을 향하거나 배치 범위를 벗어나면 계속 들고 있는다.
- 큐브를 집은 시점의 크기와 카메라 깊이 비율로 배치할 크기를 계산한다. 큐브 중심 높이는 한 변의 절반으로 맞춘다. 바로 앞에서 집을 때는 화면을 과도하게 가리지 않도록 크기 비율에 상한을 둔다.
- [main.cpp](../../project_code/Out_of_Scale/main.cpp)에서 기존 키 입력에 E를 추가했고, [Player](../../project_code/Out_of_Scale/src/core/Player.h)의 카메라 위치와 시선 방향을 TestRoom에 전달한다. 실제 방에 붙일 때는 배치 면과 충돌 판정을 각 방에 맞춰 연결한다.
- Debug·Release x64 재빌드 통과. Debug 실행 창에서 E 집기, 가까운 바닥에 축소 배치, 재집기, 먼 바닥에 확대 배치, 하늘에서 배치 거절을 확인했다. 실물 크기 변화는 격자 칸과 비교했다. 사람 검토는 미확인이다.
- 첫 시제품은 TestRoom의 바닥과 큐브 하나로 검증했다.

## 2026-11-10 — 반납함과 출구

- TestRoom에 노란 반납함과 출구 문을 추가했다. 입구를 조준했을 때 예상 큐브 크기가 내부 폭에 맞으면 E로 반납할 수 있다. 너무 크면 손에 남는다.
- 반납하면 문이 열리고 표시등이 초록색으로 바뀐다. 이동 판정은 벽과 닫힌 문을 막고, 열린 문을 통과하면 창 제목에 `Escaped`를 표시한다.
- Debug·Release x64 재빌드가 통과했다. Debug 실행 창에서 큰 큐브 반납 거절, 반납함에 접근해 축소 배치, 문 개방, W로 문을 걸어 통과해 `Escaped` 표시까지 확인했다. 닫힌 문을 향한 이동·점프 차단은 이 실행에서 별도로 시험하지 않았다.
- 집기·크기 변경과 반납·탈출 시제품을 이 기록과 함께 `yoon778`에서 공유한다. `main` 통합은 별도다.
