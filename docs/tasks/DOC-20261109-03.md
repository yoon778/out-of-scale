## 진행과 인계

- 상태: 로컬 시제품 완료
- 변경 내용: 수업 예제의 GLFW·GLEW 초기화, GLM 뷰·투영 행렬과 시간 기반 중력을 참고했다. `main.cpp`에 창·렌더링·입력 연결을 만들고, `Player`에 시점·수평 이동·점프·착지를 분리했다.
- 좌표와 조작: 예제와 같은 Y-up 좌표에서 바닥 높이는 `y = 0`이다. WASD는 보는 방향 기준으로 바닥과 평행하게 움직인다. 마우스는 시점을 돌리고 Space는 바닥에서 점프한다. Esc로 종료한다.
- 실제 파일: `.gitignore`, `OutOfScale.vcxproj`, `src/main.cpp`, `src/core/Player.h`, `src/core/Player.cpp`, 이 기록
- 빌드와 실행: `OutOfScale.vcxproj`를 Visual Studio에서 열어 `x64`로 빌드한다. 실행 파일은 `build/x64/Debug/OutOfScale.exe` 또는 `build/x64/Release/OutOfScale.exe`다. 실습 PC의 MSVC v145와 Windows SDK 10.0.26100.0에 있는 GLFW·GLEW·GLM을 사용한다.
- 빌드 검증: Debug와 Release x64 모두 통과했다. 두 빌드에서 수업 PC의 정적 GLEW 디버그 심볼 파일을 찾지 못했다는 LNK4099 경고가 나왔다.
- 창과 조작 검증: Release 실행 창의 격자 평면을 확인했다. 합성 Windows 키 입력으로 W 전진, Space 이륙과 원래 바닥 높이로 착지, Space 반복 입력 시 재점프 방지, Esc 종료를 확인했다.
- 계산 검증: MSVC에서 플레이어 이동·대각선 속도·회전 후 이동 방향·점프 및 착지·공중 재점프 방지·평면 가장자리 제한 등 11개 조건을 확인했다.
- 커밋 전 확인한 상대 작업 기록: `origin/saenu`의 `5474d3a`에서 [DOC-20261107-03](DOC-20261107-03.md)과 이전 규칙·폴더 정리 기록을 읽었다. 공유된 기록에는 이동·점프 코드와 겹치는 구현이 없었다.
- 커밋 전 빌드: 별도 출력 경로에서 Release x64 빌드를 다시 실행해 성공했다.
- 미검증: 실제 창의 마우스 입력은 검증 도구가 창 포커스를 얻지 못했다. Visual Studio에서 실행한 뒤 마우스를 움직여 시점이 돌아가는지 확인한다.
