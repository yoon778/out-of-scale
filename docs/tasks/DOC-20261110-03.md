# DOC-20261110-03 — 초승달 그림자 다리

- 2026-11-10 최윤서 작업을 지원한 Codex. `yoon778`의 `d760caf`와 [군대 반납 기록](DOC-20261110-02.md), `origin/main`과 `origin/saenu`의 관련 기록을 확인했다.
- [MilitaryRoom](../../rooms/military/MilitaryRoom.cpp)에서 창밖 달을 조준해 E로 집고, 휠을 몸 쪽으로 굴려 키운다. 초소 위 하늘을 보고 E를 누르면 그 위치와 크기로 떠 있다. 다리를 건너기 전에는 달을 다시 집어 옮길 수 있다.
- 놓인 달을 점광원으로 보고 기둥 본체·받침·상단의 모서리를 바닥과 참호 높이에 투영한다. 달이 크기 기준을 충족하고 그림자가 두 바닥을 이으며 공통 폭이 0.8 m 이상이면, 틈 위의 그림자 다각형을 그려 보행 판정에도 사용한다. 틈에서 떨어지는 동작과 복귀 경사로는 후속 작업이며 현재는 다리 밖에서 발이 멈춘다.
- [내보내기 스크립트](../../rooms/military/design/export_geometry.py)는 기존 Blender 초승달 메시를 분리한다. [공용 렌더러](../../rooms/shared/BoxRenderer.h)는 달 메시와 그림자 다각형을 그리고, [main.cpp](../../project_code/Out_of_Scale/main.cpp)는 군대 방에만 휠 입력을 전달한다.
- Debug·Release x64 재빌드 통과. Release 실행 창에서 장비 반납, 창밖 달 E 집기, 휠 확대, 공중 배치, `Bridge ready`, W로 그림자 다리를 건너 전역 출구의 `Military escaped`까지 확인했다. 별도 MSVC 공개 API 검증에서 작은 달과 잘못된 위치는 다리를 만들지 않고, 다리 밖 보행과 횡단 중 달 재집기가 차단됨을 확인했다. Blender 내보내기는 같은 원본에서 바이트 단위로 재현됐다.
- 검증한 초승달 조작과 그림자 다리 변경을 이 기록과 함께 `yoon778`에 올린다. 사람 검토와 `main` 통합은 별도다.
