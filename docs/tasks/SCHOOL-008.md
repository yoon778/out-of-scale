## 진행·인계

- 상태: 구현·Debug/Release 검사·팀 통합 검사 완료. 사용자 직접 조작 확인은 아직 없음.
- 원인: 기존 공책은 배치가 막히면 깊이를 매번 `×0.84`로 줄여 후보를 찾았음. 0.0015rad(약 0.086도)씩 시점을 바꾸는 고정 경로에서 한 단계 크기 차이 최대 0.642819배. 책상 위 후보는 중심을 조준 광선에서 위/옆으로 이동시켜 보이는 크기·중심이 달라짐.
- 변경: 군대 `dropFromAim`처럼 크기가 커지는 물체의 첫 장애물 접촉 깊이를 연속 부등식으로 계산. 공책은 거울을 향해 돌아가므로 모든 수평 회전을 포함하는 경계를 사용. 책상 위는 중심 광선과 보이는 크기를 유지하는 지지면 해를 사용. 최종 실제 공책 경계·가림·천장·플레이어 충돌 검사를 유지.
- 보존: 거울 받침대 정렬/최대 크기, 원근 공통 API, 공책 낙하, 공간이 막혔을 때 안전한 근처 내려놓기와 손의 미리보기. 군대·집 소스와 공용 API 수정 없음.
- 실제 파일: `rooms/school/SchoolRoom.cpp`, `rooms/school/tests/SchoolRoomTests.cpp`, 이 기록.
- 재현/회귀: 최초 공책을 정상 집기 → `(3.8,0,2.4)`에서 뒤쪽을 향해 pitch -1~0.5를 1,001단계로 훑음. 고정 경로 최대 크기 단계 0.642819→0.020568. 광선 중심·보이는 크기 비율·실제 물체 충돌/가림·책상 지지를 함께 검사. 다양한 장애물 모서리로 접촉 대상이 바뀌는 경우나 받침대 스냅까지 모든 변화가 연속이라는 뜻은 아님.
