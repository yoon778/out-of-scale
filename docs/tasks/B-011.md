- 숨김 OpenGL 검사 145개 통과. 잠긴 문 너머 집기 차단, 한 발판에서 잠김 유지, 두 발판 접촉 시 열림, 철판 회수 뒤 열림 유지 확인. 방독면 회수·정리, TV 진입, 달과 그림자 다리 횡단, F2 복귀까지 확인함
