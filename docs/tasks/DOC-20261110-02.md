- [MilitaryRoom](../../rooms/military/MilitaryRoom.cpp)에 보급 구역의 바리케이드 집기, 원근 배치, 반납함 크기 판정, 출입문과 야간 초소 입구까지의 보행을 연결했다. 공간과 소품은 Blender Entry 장면의 메시에서 가져왔다. [내보내기 스크립트](../../rooms/military/design/export_geometry.py)는 Blender Z-up을 게임 Y-up으로 변환하고 색과 기본 음영을 메시와 함께 저장한다. 정적 메시의 일부 베벨과 절차 재질은 간소화했다.
- [공용 원근 계산](../../rooms/shared/PerspectiveCarry.h)과 [그리기](../../rooms/shared/BoxRenderer.h)를 TestRoom과 군대 방에서 사용한다. [main.cpp](../../project_code/Out_of_Scale/main.cpp)는 기본 실행에서 군대 방을 띄우고 `--test-room`으로 격자 테스트방을 연다. 새 방과 공용 그리기 소스를 Visual Studio 프로젝트에 등록했다.
- Debug·Release x64 재빌드 통과. Release 실행 창에서 바리케이드를 가까운 바닥에 줄여 놓고, 다시 집어 반납한 다음 열린 문을 걸어 지나 `Night outpost reached` 표시를 확인했다. 안내 제목을 바닥 화살표를 따르는 문구로 고쳐 재빌드했다. Debug의 TestRoom 실행 창에서 큐브 집기·놓기를 확인했다. 내보내기 결과는 같은 Blender 원본에서 다시 생성해 파일 해시가 일치했다.
- 현재 진행 범위는 야간 초소 진입까지다. 초승달과 그림자 다리 조작, 참호 복귀는 후속 작업이다. 이 기록과 검증한 변경을 `yoon778`에 함께 올린다. 사람 검토와 `main` 통합은 별도다.
