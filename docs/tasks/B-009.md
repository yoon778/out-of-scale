# B-009 — 군대·내 방 구성 확정

- 2026-11-16 최윤서 작업 지원. `origin/main` `853fd1b`, `origin/saenu` `5474d3a`, `yoon778` `0fcbf3d`와 각 브랜치의 관련 기획·작업 기록을 확인함
- [게임 기획서](../../illusion-escape-game-plan.md)에 초승달 자유 배치, 실제 그림자 모양의 투명 발판, 깊어진 참호와 입구 쪽 사다리, 연병장의 원근 계단과 높은 초소 문을 기록함
- RPG는 연병장 거치대의 이스터에그로 정함. 내 방에서는 군대 미니어처의 같은 거치대에서 RPG를 꺼내 키우고 금 간 가벽을 부숨. 문틀이 드러나면 작은 문짝을 키워 설치하고 걸어서 탈출함
- 학교·군대·회사 미니어처는 기존 배치와 소품을 담고, 내 방 모형의 위치·회전 조작은 대응하는 실물에 반영함. 새누와는 회사 방향 연결 지점과 학교·회사 소품의 모형 사용을 추후 맞춤
- 기획서와 이 기록을 문서 전용 커밋으로 `yoon778`과 `main`에 공유함. Git에서 통합 이력 확인 가능. 새 기능은 구현 예정이며 검증은 문서 내용·링크·변경 범위에 한정함

- 연병장과 내 방 계획은 이후 작업으로 유지. 이번 변경은 작업 기록과 함께 `yoon778`로 공유함
