## 변경과 인계

- [Blender 원본](<../../rooms/military/design/군대 방 맵.blend>)에 생활관 천장 보·형광등·군화·창밖 능선, 동굴 양쪽 입구 암층·금속 프레임, 야외 감시탑 패널·참호 벽면·배수구를 추가함. 정적 메시가 약 2,365개 삼각형 순증함
- [내보내기 스크립트](../../rooms/military/design/export_geometry.py)가 생활관 45묶음·야외 20묶음의 메시와 경계를 [게임 파일](../../rooms/military/MilitaryGeometry.inc)로 생성함. [렌더러](../../rooms/military/MilitaryRoom.cpp)는 [카메라 시야](../../rooms/military/MilitaryVisibility.h)에 걸리는 묶음만 보내며, 연속 묶음은 한 번에 그림
- [동굴](../../rooms/military/CaveScene.inc)은 카메라 밖 면과 반사띠의 달빛 계산을 건너뜀. 시야를 막는 어두운 면은 깊이 판정에 사용함. 화면 밖 달도 조명·그림자·다리 판정에 참여함
- 현재 맵만 갱신·렌더링하는 공용 루프와 군대 내부의 생활관·야외 분기를 사용함. 비활성 맵의 상태는 메모리에 유지함. 학교와 공용 코드, 퍼즐 개체 데이터 수정 없음

## 검증

- Blender 재내보내기 해시 일치. 모든 정적 메시 정점이 해당 묶음 경계 안에 있음. 방독면 등 생활관 상호작용 물품과 초승달 데이터 일치
- Debug·Release x64 빌드 통과. 숨김 OpenGL 검사 181개 통과. 장비함 개방, 물품 정리, TV 통과, 달빛·반사띠, 그림자 다리와 사다리, F2 복귀 확인
- RX 9070 XT, 1024×640, 동일 시점 16개 비교. 제출 삼각형 평균은 생활관 75,482 → 43,499개(42.4% 감소), 야외 15,071 → 11,400개(24.4% 감소). 야외 정면 일부에서는 추가 모델링만큼 제출량이 증가함
- 시점별 96프레임 GPU 시간 중앙값의 평균은 생활관 0.046 → 0.021ms, 야외 0.026 → 0.017ms. 실제 전체화면 플레이 FPS와 사람의 시각 평가는 미확인
- 새누 공유 기록은 `origin/main` `615de34`의 학교·공용 작업과 `origin/saenu` `5474d3a` 확인. 공통 API 변경 없음
- Git 공유 대상은 이 기록을 포함한 `origin/yoon778` 커밋. `main` 통합은 별도
